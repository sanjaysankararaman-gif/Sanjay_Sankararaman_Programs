# Web Programming College Work

Web programming exercises from my B.Tech Information Technology course at Shiv Nadar University. Each exercise is a small multi-section web page built with HTML, with a PDF copy of the output for submission.

## Contents

| Exercise | Page | What It Covers |
|---|---|---|
| [Ex 4](./Ex_4) | `Tourism.html` | A tourism page for Tamil Nadu, with sections for hill stations (Ooty, Kodaikanal), beaches and heritage sites (Kanyakumari, Rameswaram, Madurai, Mahabalipuram), plus images and icons |
| [Ex 5](./Ex_5) | `QuickBite.html` | A sample food delivery landing page showing menu items (biryani, pizza, desserts, smoothies), a delivery section |

## Tech Used

- **HTML** for page structure, images and layout
- **CSS** for styling 
- **BOOTSTRAP5** was also used in many cases for styling

## Running the Pages

Download or clone the repository, then open `Tourism.html` or `QuickBite.html` in any browser. Each page sits in its exercise folder next to its images, so keep them together.

## Notes

Each exercise folder also has a PDF of the rendered page.
